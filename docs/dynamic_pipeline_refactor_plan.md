# 动态模型采集、解析和上传重构计划

## 目标与边界

- AW 只提供采集基础接口、命令执行和 Trace 等通用设备能力；具体日志采集由动态模型维护。
- 动态模型采集为基本能力，采集项及解析映射使用模块内配置，不放入项目根配置。
- pytest 层只连接生命周期；保留现有用例 API、采集时序、服务端协议和报告兼容性。
- 用例及轮次采集、解析、上传各自记录状态；解析结果先本地保存，上传为可选步骤。
- 服务端 task ID 仅在启用上传时申请；本地运行标识独立。失败补传必须先确认服务端幂等协议，不擅自重试可能重复入库的结果。
